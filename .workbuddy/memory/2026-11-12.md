## TB6612 驱动 SPL → HAL 移植（SHUIBENG / STM32F103C8T6）

- 原始代码：立创 LCKFB 例程（标准库），示例引脚 PA1=AIN1、PA2=AIN2、PA6=PWMA(TIM3_CH1)。
- 本工程实际接法（用户确认）：AIN1=PB12、AIN2=PB13、PWMA=PB1(TIM3_CH4)；
  B 通道 BIN1=PB14、BIN2=PB15、PWMB=PB0(TIM3_CH3)；STBY 接 3.3V。
- 改动文件：
  - `hareware/tb6612.h` / `hareware/tb6612.c`：重写为 HAL 版，引脚集中在头部宏映射区；
    接口 `TB6612_Init(pre, per)`、`TB6612_InitWithHandle(&htim)`、`AO_Control/BO_Control`、
    `AO_Stop/AO_Brake/BO_Stop/BO_Brake/TB6612_Stop`、`TB6612_GetPeriod`。
    实现要点：独立 static 句柄 s_tb_tim，PSC=pre-1、ARR=per（与 SPL 语义一致）；
    `__HAL_TIM_SET_COMPARE` 替代 `TIM_SetCompare1`。
  - `Core/Src/main.c`：原来 USER CODE 2 里错误嵌入了第二个 `main()`（编译不过），已清理；
    改为 `TB6612_Init(8, 1000)` + 两路电机正反转演示。
  - `EWARM/SHUIBENG.ewp`：新增 Hardware 组（tb6612.c）与 include 路径 `../hareware`。
- 重要环境事实：`SystemClock_Config` 为 HSI 8MHz、PLL 未开；APB1 不分频。
  因此 PWM 1kHz 需要 pre=8（72MHz 时才用 pre=72）。CubeMX 里 TIM3 默认 PSC=0/ARR=65535 ≈122Hz。
- 注意：CubeMX 重新生成会覆盖 .ewp 里的手动添加（Hardware 组 + include 路径），需重新加。

## 追加：PID（最终形态：位置式）

- 新增 `hareware/pid.c` / `hareware/pid.h`。最初写的是增量式，用户要求改成位置式（更好理解），已改。
  公式：`u = Kp*e + Ki*Σe + Kd*(e - e_last)`，带积分限幅（限到 out_max/Ki）与输出限幅。
- 结构体字段：Kp/Ki/Kd/target/actual/err/err_last/integral/out/out_max。
- 接口：`PID_Init(&pid, kp, ki, kd, out_max)` / `PID_Calc(&pid, target, actual)` / `PID_Reset(&pid)`。
- `Core/Src/main.c`：`MotorA_SpeedLoop()` 每 50ms 读 `__HAL_TIM_GET_COUNTER(&htim2)`
  （int16_t 处理 16 位溢出）作为实际速度；PID 输出有符号 → 正数 `AO_Control(1,u)`、负数 `AO_Control(0,-u)`。
  `HAL_TIM_Encoder_Start(&htim2, TIM_CHANNEL_ALL)`；`PID_Init(&pid_a, 1.0f, 0.05f, 0.0f, 1000.0f)`。
- 宏：SPEED_TARGET=800（编码器计数/50ms）、SPEED_PERIOD=50。
- 注意：TIM2 编码器在 .ioc 里是 `TIM_ENCODERMODE_TI1`（1 倍频），要更高分辨率应改 TI12。
- .ewp Hardware 组已加入 pid.c。
